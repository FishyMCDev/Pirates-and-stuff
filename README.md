
# **Fishy Cutlasses**

FishyCutlasses is a plugin for PiratesMC to add cutlasses to the game without any player-side mods of any kind. It does so by utilizing the consumable component for dfferent types of textured swords. It can also replace sword recipes and swords as an item globally.

**The cutlasses** 
- Can block on right click 
- Have a block and dash stamina! 
- Have different variants 

**Future Plans** 
- Fruits to increase/decrease stamina of cutlasses :P 


**Using the project** 

Download the .jar from releases, and plop it into a server with: 

- Java 21 
- Minecraft version 1.21.11+ 
- Folia supported!
