# Pirates N' More!

Pirates N' More aims to add the following features to minecraft:
- Custom Cutlasses
- Custom Forging System
- Custom Datapack that is Pirate-Themed

The plugins (Cutlass and Forge plugins), are for version 1.21.11 - 26.1.2.

# The Datapack

The datapack works on version **26.1.2** only.

It has the following features:
- Continent style generation
- New biomes
- End and Nether oceans (With colors)
- End and nether islands
- Custom structures

# Installation

To **install the plugins**

- Stop your server
- Open your server's /plugins folder
- Place in FishyForge.jar and FishyCutlasses.jar
- Start your server
- Enjoy playing!

To **install the datapack**

- Stop your server
- Place the datapack in the /world/datapacks folder
- Start your server

Verify the server version is 1.21.11 - 26.1.2 for the plugins, and if you want the datapack, 26.1.2 is best.

# Usage

- Use the command `/cutlasses` to see the commands to give cutlasses to players
- Right click while holding the cutlass to block, sneak to dash
- Stand still to regen dash stamina

- Use the command `/fishyforge` to see the commands to use the forge
- Watch this video to see how the forge works: https://youtu.be/JcB3DCDgQ-M
